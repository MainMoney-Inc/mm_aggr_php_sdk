# PHP SDK examples

Standalone mini-shop that uses `mainmoney/mm-aggr-php-sdk` as a Composer
package. Start this backend, then point a
[JS/TS frontend example](https://github.com/MainMoney-Inc/mm_aggr_js_sdk/tree/main/examples)
at it with `VITE_MERCHANT_BACKEND_URL`.

| Example | Port |
| --- | --- |
| [laravel](laravel/) | 8003 |
